# netzli demo site

A tiny static website built with HTML, CSS, JavaScript, and Vite.

```sh
npm install
npm run dev
```

Build for deployment:

```sh
npm run build
```

Publish the generated `dist/` directory. Assets use relative paths so the site also works under a subpath.

Preview the production build locally with `npm run preview`.

[netzli.ch](https://netzli.ch)
